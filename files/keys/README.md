# Публичные ssh-ключи

Сюда кладутся **только публичные** половины ключей (`*.pub`). Они не
секрет: по публичному ключу нельзя восстановить приватный, поэтому их
безопасно держать в открытом репозитории.

Приватным ключам (`id_ed25519` без `.pub`) здесь не место — они уехали бы
в `/gnu/store`, который читается любым пользователем машины. См. раздел
«Секреты» в корневом README.

## Добавить свой ключ

```sh
# на машине, с которой будете ходить по ssh
cat ~/.ssh/id_ed25519.pub
```

Сохраните вывод в файл вида `dyens.pub`, затем подключите его
в `systems/<host>.scm`:

```scheme
 #:ssh-authorized-keys `(("dyens" ,(local-file "../files/keys/dyens.pub")))
```

Если ключа ещё нет:

```sh
ssh-keygen -t ed25519 -C "dyens@$(hostname)"
```

## Порядок отключения пароля

1. Добавили ключ, `sudo -i guix system reconfigure ...`
2. **Проверили**, что вход по ключу работает: `ssh -p 10022 dyens@127.0.0.1`
3. Только теперь `#:ssh-password-auth? #f` и ещё один reconfigure.

Порядок важен: выключив пароль до проверки, вы потеряете доступ по ssh,
и останется только консоль VM.
