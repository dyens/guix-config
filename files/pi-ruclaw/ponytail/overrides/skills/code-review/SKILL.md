# Code review — Ponytail

Read `../ponytail-review/SKILL.md` completely and use its review method and output.
The assigned original task and exact base/head define scope; do not default to an
unrelated last commit or dirty checkout. Review the committed snapshot with explicit
Git SHAs and follow its connected code. No default bundled/risk-checklist workflow.

Read `../implement/references/result-contract.md` for artifact transport. The
Ponytail report belongs in report.md; short.md indexes it. Do not modify product
code, execute candidate-controlled scripts/tests or publish remotely as a reviewer.
The parent runs checks and owns fixes. No nested delegation. Use approved evidence
as evidence, not as proof that every requirement is met. Report unavailable scope
and checks honestly. A Ship verdict is not publication permission or production
acceptance. Retain original reports when inspecting follow-up deltas.
